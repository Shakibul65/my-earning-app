# EarnClick — PTC (Paid To Click) সাইট

একটি সাধারণ Flask ভিত্তিক ওয়েবসাইট, যেখানে ইউজাররা বিজ্ঞাপন দেখে টাকা আয় করতে পারবে।

## ফিচার
- ইউজার রেজিস্ট্রেশন ও লগইন
- প্রতিদিন নতুন বিজ্ঞাপন দেখে আয় (একই বিজ্ঞাপন দিনে একবার)
- টাইমার-ভিত্তিক ভিউ ভেরিফিকেশন (নির্দিষ্ট সময় দেখা বাধ্যতামূলক)
- ব্যালেন্স ও লেনদেন হিস্ট্রি
- উত্তোলন (Withdraw) সিস্টেম — bKash / Nagad / Rocket / Bank
- অ্যাডমিন প্যানেল — বিজ্ঞাপন যোগ/বন্ধ, উত্তোলন অনুমোদন/প্রত্যাখ্যান

## ইনস্টলেশন

```bash
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## ডাটাবেস সেটআপ (প্রথমবার)

```bash
flask --app app init-db
```

এটি একটি ডিফল্ট অ্যাডমিন অ্যাকাউন্ট তৈরি করবে:
- ইউজারনেম: `admin`
- পাসওয়ার্ড: `admin123`

**⚠️ প্রোডাকশনে যাওয়ার আগে অবশ্যই এই পাসওয়ার্ড পরিবর্তন করুন এবং `app.py`-তে `SECRET_KEY` পরিবর্তন করুন।**

## রান করা

```bash
python app.py
```

ব্রাউজারে যান: http://localhost:5000

## গুরুত্বপূর্ণ বাস্তবতা (Real-World Considerations)

PTC সাইট চালু করার আগে নিচের বিষয়গুলো মাথায় রাখা জরুরি:

1. **বিজ্ঞাপনদাতা প্রয়োজন**: আসল আয়ের জন্য তোমার নিজের অ্যাডভার্টাইজার/স্পনসর দরকার হবে, অথবা Google AdSense-এর মতো নেটওয়ার্ক ব্যবহার করতে হবে — তবে বেশিরভাগ বড় অ্যাড নেটওয়ার্ক (AdSense সহ) PTC/click-to-earn মডেলের সাইটে বিজ্ঞাপন দেখাতে **নিষেধ করে** (policy violation), কারণ এটি "invalid traffic" হিসেবে গণ্য হয়। তাই AdSense দিয়ে সরাসরি PTC সাইট চালানো ঝুঁকিপূর্ণ — অ্যাকাউন্ট ব্যান হতে পারে।
2. **বট/ফ্রড প্রতিরোধ**: এই কোডে বেসিক সুরক্ষা (দৈনিক এক ভিউ, টাইমার) আছে, কিন্তু বাস্তব সাইটে CAPTCHA, IP-ট্র্যাকিং, ডিভাইস ফিঙ্গারপ্রিন্টিং ইত্যাদি লাগবে fraud ঠেকাতে।
3. **পেমেন্ট প্রসেসিং**: এখানে উত্তোলন শুধু ম্যানুয়াল অ্যাডমিন অ্যাপ্রুভাল সিস্টেম — bKash/Nagad-এর সাথে অটোমেটেড পেআউট ইন্টিগ্রেশন করতে চাইলে তাদের Merchant API ব্যবহার করতে হবে (আলাদা রেজিস্ট্রেশন লাগবে)।
4. **আইনি/ব্যবসায়িক দিক**: বাংলাদেশে এ ধরনের সাইট চালাতে ব্যবসা নিবন্ধন ও পেমেন্ট প্রসেসিং সংক্রান্ত নিয়ম মানা প্রয়োজন হতে পারে।
